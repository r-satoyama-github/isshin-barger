# 🍔 Isshin Barger レジ

おみせやさんごっこ用の、ハンバーガー屋さんのレジアプリです。iPad を横向きにして使う想定です。

## あそびかた

1. **「おみせを ひらく」** をタッチ（ここで音と声が使えるようになります）
2. おきゃくさんの注文を聞いて、商品をタッチ → 右の「ちゅうもん」に入ります
   - ドリンクは S / M / L のサイズを選びます
   - セットは、バーガー＋ポテト＋ドリンク(M) で 100えん おトク。ドリンクを選びます
   - ＋ / − で数を変えられます。🗑️ で全部消せます
3. **「おかいけい」** → おきゃくさんからもらったお金（1000円札・500円・100円・50円・10円）をタッチ
   - 足りないと「あと ○○えん」、多いと「おつり ○○えん」と、返すお金の内訳が出ます
   - 並んだお金をタッチすると、そのお金を取り消せます
4. **「おかいけい かんりょう」** → レシートと注文番号が出ます
5. **「つぎの おきゃくさま」** で次のお客さんへ

ヘッダーの「いらっしゃいませ」などのボタンを押すと、アプリがしゃべります。

### おとな向け設定
右上の ⚙️ を **長押し（約1秒）** すると設定が開きます。
- 効果音 ON/OFF
- 読み上げ ON/OFF
- 注文番号を 1 に戻す

## メニューを変えるには
[menu.js](menu.js) を編集します。店名・商品名・絵文字・値段・セット割引額を変えられます。

## iPad で使うコツ
- Safari で開き、共有ボタン →「ホーム画面に追加」すると全画面アプリのように使えます
- 声が出ないときは、iPad のマナースイッチ・音量を確認してください

## 手元で動かす
ES modules を使っているので、ファイルを直接開くのではなく簡易サーバー経由で開きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## GitHub Pages で公開
1. このフォルダを GitHub リポジトリに push
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

※ 無料プランの GitHub Pages は公開リポジトリが必要で、URL を知っている人は誰でも見られます（検索エンジンには載らないよう `noindex` を設定済み）。
